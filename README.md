BrightStar Electronics Website

A modern, responsive electronics shopping website built using HTML, CSS and JavaScript.

Project Overview

BrightStar Electronics is a demonstration e-commerce website designed to showcase electronics products through a clean and user-friendly interface.

Features

- Responsive navigation
- Product catalogue
- Product search
- Category filtering
- Shopping cart
- Quantity controls
- Remove items from cart
- Estimated cart total
- WhatsApp enquiry functionality
- Responsive design

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

Project Structure

- "index.html" – Website structure
- "style.css" – Website styling
- "script.js" – Interactive functionality
